# EventArgs Internal Knowledge Copilot: Security & Architecture

## Security Boundary
The EventArgs Knowledge Copilot runs strictly within local offline boundaries. All document parsing, embedding generation, vector persistence, and response synthesis are executed locally without external cloud API dependencies.

## Citation & Grounding Rules
1. Every answer produced by the copilot must include explicit source citations containing filename/table name, source ID, and chunk index.
2. If evidence relevance score falls below 0.70 or retrieved evidence count is under the minimum requirement, the system issues a strict refusal payload (`NoRelevantContext` or `InsufficientEvidence`).
3. Model priors are never used to hallucinate answers when evidence is missing.

## Vector Storage
PostgreSQL with pgvector is used for cosine similarity search over 768-dimensional embeddings generated by local Ollama instances.
